VluxySF

This item only works when running on the client. ClientThis item only works when running on the server. Server

Vluxy Sound Factory. Build your sounds in Studio once, then fetch any of them by name from the server or the client. 

local sound = VluxySF.Fetch("MySound")
sound:Play()

Types​

Wrapped<T>​

</>
type Wrapped<T> = VluxySF

The library returned by WithWrapper. The same as VluxySF, except that Fetch and TryFetch return the wrapper instead of the Sound.

Functions​

Fetch​

RequiresSchema
</>
VluxySF.Fetch(
name: string,--

The name of the Sound.

parent: Instance?,--

Parent of the Sound.

preset: ((Sound) → ())?--

Preset to apply before parenting.

) → Sound--

The new Sound.

Creates the Sound with that name. If the name is not in the schema, a warning is printed and a silent blank Sound named VluxySF_Blank_Sound is returned instead, so calling code never has to nil-check.

INFO
  • A warmed sound (see Cache) is cloned from its template.
  • A sound fetched without a parent is placed in SoundService.UnattachedSounds. So is one whose parent refused it (a locked or destroyed Instance), with a warning. A parent that is not an Instance, or a preset that is not a function, is warned about and ignored.
  • Called before the library has started, it warns once and returns a blank Sound instead of erroring, so early game code keeps running. The blank is parented to parent when one was given and stays unparented otherwise; the preset is not applied to it.
  • An error thrown by the preset is yours and propagates; the sound it was applied to is destroyed first.
local mySound = VluxySF.Fetch("MySound")
mySound.Volume = 0.3

local echo = mySound:FindFirstChild("EchoSoundEffect")
if echo then
	echo.WetLevel = 1.3
end

mySound:Play()

TryFetch​

RequiresSchema
</>
VluxySF.TryFetch(
name: string,--

The name of the Sound.

parent: Instance?,--

Parent of the Sound.

preset: ((Sound) → ())?--

Preset to apply before parenting.

) → Sound?--

The new Sound, or nil.

The same as Fetch, but returns nil instead of a blank sound when the name is not in the schema, or when the library has not started yet. Use it for names built at runtime or sounds that may not exist. 

local voiceLine = VluxySF.TryFetch(`VO_{npcName}`, head)

if voiceLine then
	voiceLine:Play()
end

OneShot​

RequiresSchema
</>
VluxySF.OneShot(
name: string,--

The name of the Sound.

parent: Instance?,--

Parent of the Sound.

preset: ((Sound) → ())?--

Preset to apply before parenting.

) → () → ()--

Stops and destroys the Sound early.

Plays a sound once and cleans it up: builds it, turns looping off, plays it and destroys it when it ends. Returns a function that stops and destroys it early.

Nothing has to wait for the audio to load: Roblox holds a played sound until its audio arrives and starts it from the beginning. If the audio has not loaded within 10 seconds (deleted, moderated or private audio never does), a warning is printed and the sound is destroyed. With a name that is not in the schema, or before the library has started, a warning is printed and nothing plays. Destroying the parent while the sound plays is fine: the sound goes with it and nothing is reported. 

VluxySF.OneShot("Hit", character.HumanoidRootPart)

local stop = VluxySF.OneShot("Charge")
-- later, if it has to end early:
stop()
INFO

Sound.Played fires and IsPlaying turns true as soon as the sound is played, before its audio has loaded. Code that needs the sound to be audible should wait for Sound.Loaded.

WithWrapper​

</>
VluxySF.WithWrapper(
wrap: (Sound) → T--

Turns a fetched Sound into your wrapper.

) → Wrapped<T>--

The library with wrapping fetch functions.

Returns a copy of the library whose Fetch and TryFetch pass every fetched Sound through wrap and return what it returns. Use it to get your own sound class, with methods like fades, out of every fetch.

The copy is fully typed: whatever type wrap returns is what Fetch returns. VluxySF itself is not changed, so other scripts and packages that require it still get plain Sounds.

TIP

Call this once in a module of your own and require that module everywhere. The Wrapping Sounds guide shows the setup. 

local Sounds = VluxySF.WithWrapper(function(sound)
	return MySoundClass.new(sound)
end)

Sounds.Fetch("MySound"):FadeIn(1)
INFO
  • Presets still receive the Sound before it is wrapped.
  • Fetch wraps the blank sound it returns for an unknown name. TryFetch returns nil without calling wrap.
  • OneShot is unchanged, since a one-shot cleans itself up.
  • If wrap errors, the fetched Sound is destroyed and the error is passed on, since it comes from your code.
